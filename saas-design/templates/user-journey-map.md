## Filled example (B2B regulatory SaaS)

For reference, here is a partially filled example based on the DnXT Solutions case study:

| | Discovery | Interest | Consideration | Acquisition |
|--|-----------|----------|---------------|-------------|
| **Actions** | Finds site via LinkedIn or colleague recommendation | Lands on homepage; scans hero; looks for customer logos | Reads about products; compares cost; checks references | Submits contact form or requests demo |
| **Goals** | Find a new regulatory platform to replace failing one | Understand if this company is credible and relevant | Know if the product solves her specific problems; understand cost | Start the process without over-committing |
| **Feelings** | 😐 Skeptical; has been burned by bad tools before | 😐→🙂 If customer references visible; 😐 if none found | 😐 Interested but cautious; needs evidence | 🙂 If the process is simple; 😕 if forced to call |
| **Pain points** | Hard to find the site; loads slowly | References from similar companies not visible; too much generic content | Generic info that requires a phone call to decode; unclear pricing | Acquisition process unclear; having to commit before seeing enough |
| **Opportunities** | Improve SEO; LinkedIn presence; peer referral program | Show customer logos and quotes early; keep hero concise | Case studies with similar companies; FAQ section; pricing range | Visualize the 3-step process ("Submit form → Free consultation → Meet your goals"); reduce cold-call pressure |

## Design recommendations from this journey map

List the website changes most directly supported by the journey map findings:

| Finding from journey | Design action |
|---------------------|---------------|
| User discovers via LinkedIn/recommendation | Ensure site loads fast; URL is shareable |
| First looks for customer references | Customer logos + quotes in first 2 sections |
| Wants to evaluate without a call | Self-service info; FAQ; avoid "contact us for pricing" |
| Risk-averse; needs process clarity | Visualized acquisition steps (3-step diagram) |
| Busy; first scroll is a skim | Short sections; clear headings; minimal text per section |
