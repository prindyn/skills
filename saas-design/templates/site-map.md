# Site Map Template

A site map defines the structure and hierarchy of the website before any visual design work begins. Agree on the site map with the client before starting wireframes — changing structure after visual design has started is expensive.

---

## Home page structure

### Recommended baseline for B2B SaaS (customize as needed)

```
┌─────────────────────────────────────────────────────────────────┐
│  HEADER                                                         │
│  Logo + nav links to pages/sections + primary CTA button        │
├─────────────────────────────────────────────────────────────────┤
│  SECTION 1: HERO (Welcome / Introduction)                       │
│  Tagline + 1–2 sentence description + visual element            │
│  CTA: [book a demo / learn more / see how it works]             │
├─────────────────────────────────────────────────────────────────┤
│  SECTION 2: WHY US                                              │
│  Key differentiators + stats/ratings                            │
│  (No CTA — let the content do the work)                         │
├─────────────────────────────────────────────────────────────────┤
│  SECTION 3: CUSTOMER FEEDBACK / SOCIAL PROOF                    │
│  Testimonial quotes + customer photos + (optional) logos        │
│  CTA: [read case studies / see all reviews]                     │
├─────────────────────────────────────────────────────────────────┤
│  SECTION 4: PRODUCTS / SERVICES                                 │
│  Short product cards with icon + name + 1-sentence description  │
│  CTA: [learn more] per card — links to product pages            │
├─────────────────────────────────────────────────────────────────┤
│  SECTION 5: (optional) BLOG / RESOURCES HIGHLIGHT              │
│  Add when 3+ posts exist — remove until then to avoid           │
│  an empty or stale section                                      │
├─────────────────────────────────────────────────────────────────┤
│  SECTION 6: GET IN TOUCH / CONTACT                              │
│  Visualized steps (3-step process) + contact form               │
│  CTA: [submit form]                                             │
├─────────────────────────────────────────────────────────────────┤
│  FOOTER                                                         │
│  Contact info + LinkedIn/social + nav links (mirror header)     │
│  Short company description (2–3 sentences)                      │
└─────────────────────────────────────────────────────────────────┘
```

**Rationale for this order:**
- Hero establishes what the company does (2 seconds to make an impression)
- Why us creates initial interest (differentiators and credibility signals)
- Customer feedback early builds trust before the user reaches the product pitch
- Products/services come after trust is established, not before
- Contact appears last — the user should want to reach out, not be pushed to

## Site navigation structure

Define the top-level navigation items that appear in the header:

```
Logo | [Nav item 1] | [Nav item 2] | [Nav item 3] | [Nav item 4] | [CTA Button]
```

**Recommended for B2B SaaS:**
```
Logo | Products | Services | About | Blog | Contact us [button]
```

**Rules:**
- Maximum 5–6 navigation items (more creates decision paralysis)
- The CTA button should be visually distinct (colored button, not just a link)
- Consider a "Login" link separate from the main navigation (for existing customers)

---

## Cookie consent placement

If the site will have analytics cookies (Google Analytics, etc.), include a cookie consent banner. Note this in the site map:

```
[Cookie/Consent banner — appears on first visit, anchored to bottom of screen]
```

This is a legal requirement in the EU (GDPR) and increasingly expected globally.
